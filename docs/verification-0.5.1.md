# 0.5.1 修补记录

本次基于已提交的 0.5.0 追加修复，保留原提交历史。GitHub 推送、发布与现有部署切换未执行。

## 修复范围

- 暂停未经完整 spike 验收的 Paper/皮肤入口，删除单独启动 Java、反序命令及四秒后强杀逻辑；保留明确提示。
- Paper 固定版本必须与选择一致；类型目录分离，组件准备采用临时目录，下载失败保留旧配置并清理新临时目录。
- 兼容 0.5.0 遗留 Paper 目录：回到原版使用独立目录，保留旧 jar 与存档。
- QQ 重启后提供可确认的重新启动入口，清理旧二维码，支持已保存登录态的真实协议检测。
- QQ 原生模块的数据路径通过进程内桥接指向专属 profile，避免单靠环境变量时复用系统 QQ 数据位置。未调用改变系统设置的原生 setter。
- 状态版本与测试启动入口从包元数据读取；更新安装与限制说明。
- 身体试用、应用和回滚的语法检查正确使用 Node 解析结果中的可执行文件与环境，修复 0.3.1 接口变更后的遗漏。
