# 小白第一次用：从零到能聊天

> 假设：你用的是 Windows，刚听说这个插件，电脑上**还没有 DSH**。
> 每一步都写清楚"看到什么、点哪里"。看到和这里不一样，就先停下来。

## 先看这个：整件事可以交给 DSH 自己做

**上面这些步骤，除了"装 DSH"本身，全都可以让 DSH 帮你做。**

装好 DSH 之后，在它的对话里说一句就行：

```
帮我装这个插件：https://github.com/Red0tsnow/dsh-companion
```

它自己会下载、打包、装进 profile、告诉你什么时候要重启。同理，装完之后你还想问"怎么开世界""QQ 怎么连"，直接问它。

**那这份文档还有什么用？** 两个用途：

1. 你想知道**到底发生了什么**，不是让 AI 黑箱操作
2. **DSH 答不上来的时候**，你手上有准确的参考

所以下面每一步都标了"能不能让 DSH 代做"。

---

## 第 0 步：先确认这件事你能接受

这个插件**不是 App**。它得装在一个叫 **DSH（DeepSeek Harness）** 的东西上才能用，就像浏览器插件必须有浏览器。

如果你只是想"下个软件就能聊"——那这个不适合你，现在就可以停。

要继续，你需要：

- 一台 Windows 电脑
- 一个能用的 AI 模型账号（DSH 里配，模型可能要花钱）
- 大约 30 分钟，和一点耐心

---

## 第 1 步：装 DSH（约 15 分钟）

DSH 是宿主程序，插件挂在它上面跑。**这一步只能自己做**——没有 DSH 就没有能替你干活的东西。

1. 打开 https://github.com/deepseek-ai/dsh ，按里面的说明下载 Windows 版
2. 装好之后**先不管插件**，打开 DSH，随便发一句话
3. **必须能收到回复**才算这一步过了

> 如果 DSH 自己聊不起来，插件装了也没用。这一步别跳。

**顺便确认 Node 版本**（插件要用）：打开"命令提示符"，输入

```
node -v
```

显示 `v22` 或更高就行。没有或版本低，去 https://nodejs.org/ 装 LTS 版。

---

## 第 2 步：装插件（约 3 分钟）

> **可以交给 DSH 做。** 直接跟它说"帮我装这个插件：<仓库地址>"，它会下载、打包、装好。
> 下面是自己动手的版本。

1. 打开 https://github.com/Red0tsnow/dsh-companion/releases
2. 找到最新的那一版，下载 **`dsh-companion-x.x.x.tgz`**（就一个文件）
3. 记住它下载到哪了，通常是"下载"文件夹
4. 打开"命令提示符"，粘贴下面这行（**把路径换成你实际的位置**）：

```
dsh plugin --profile desktop add "<你下载到的位置>\dsh-companion-0.7.2.tgz"
```

**路径怎么填**：在下载文件夹里右键那个文件 → 复制文件地址 → 粘进来（保留两边的引号）。

5. 看到安装成功的提示后，**完全退出 DSH，再重新打开**

> 不是关窗口，要真的退出（任务栏右下角确认它没了）。

---

## 第 3 步：打开面板（约 2 分钟）

1. DSH 重新打开后，进 **设置**
2. 左边找到 **「鲸屋 / Whale House」**，点进去
3. 你会看到一个面板，最上面是「人设」

**第一件事：看她能不能用**

面板上有一行「**宿主模型：可用 / 未配置 / 未知**」。

- **可用** → 继续
- **未配置** → 点旁边的「重新检查」，它会告诉你去哪登录模型
- **未知** → 先随便和 DSH 聊一句，回来再点「重新检查」

---

## 第 4 步：给她一个人设（约 5 分钟）

> **可以交给 DSH 做。** 跟它说"帮我写一个人设：她叫小满，是我室友，说话直接"，它会填进去。

这一步决定"她是谁"。**不写也能用**，但会是个很空的角色。

1. 填 **角色名**（比如"小满"）
2. 填 **你们的关系**（比如"朋友"、"室友"）
3. 填 **语气**（比如"话少，直接"、"活泼，爱开玩笑"）
4. 填 **她怎么称呼你**
5. 中间那个大框是「**完整人设**」，可以：
   - 点「**载入空白模板**」——给你一个骨架，自己填
   - 点「**载入示例**」——看一个完整例子长什么样
6. 填完点「**保存人设**」

**注意**：那个框有 **4000 字上限**，右下角会显示"还剩多少"。超了不让保存——这是故意的，超了会被模型截断。

---

## 第 5 步：跟她说第一句话（1 分钟）

**这一步最容易搞错，看清楚。**

点「**打开角色对话**」→ DSH 会让你**选一个工作空间** → 选完之后你会发现：**那里面还不是她**，是 DSH 自己的会话，发消息也不像人设在回。

真正能跟她说话的是**面板里那个折叠行「在这里聊一句」**：

1. 回到插件面板（设置 → 鲸屋）
2. 人设下面有一行「**在这里聊一句**」，点开它
3. 输入框写一句，比如"你好"
4. 点「**发送**」，下面会显示你和她的对话

> 如果这行显示的是「当前为独立面板预览；角色对话需在 DSH 中打开」，说明你现在在预览里，不是在真的 DSH 里——那种情况下没有回复是正常的。

**先随便说一句**，比如"你好"。

- 有回复 → 成了，插件已经在工作
- 没回复 → 回到第 3 步看「宿主模型」那行

**到这里，最小可用已经完成。** 下面的都是可选。

---

## 第 6 步（可选）：让她进 Minecraft

> **可以交给 DSH 做。** 跟它说"帮我开一个 Minecraft 世界"，它会走同一个向导。

面板上「**她可以去的地方**」有四个方块，点 Minecraft 那张的「**开始一起玩**」。

向导会问你"你有世界吗"，三个选项：

| 选项 | 适合谁 |
|---|---|
| **没有，帮我准备一个**（推荐） | 大部分人。插件自己下服务端、准备 Java |
| 我自己开一个，对局域网开放 | 你已经有游戏客户端，想用自己的存档 |
| 我已经有服务端目录 | 你本来就开服 |

选第一个，然后：

1. 版本下拉框默认选好了（**26.1**），不用改
2. 服务端类型保持「**原版**」（最快）
3. 勾选「**允许从官方来源下载所需组件**」
4. 勾选「**我已阅读并同意 Minecraft 使用协议**」
5. 点「**准备并开启世界**」

**这时候要等几分钟**（下服务端、生成世界）。中途关掉会白等，耐心一点。

完成后会显示一个地址（像 `127.0.0.1:25565`）。**复制它**，打开你自己的 Minecraft Java 版客户端 → 多人游戏 → 添加服务器 → 粘贴 → 加入。

进游戏后，你会看见她站在那儿。

> 要进世界玩，你需要**自己的 Minecraft 正版客户端**。插件不提供游戏。

---

## 第 7 步（可选）：让她上 QQ

> **可以交给 DSH 做，但扫码必须你自己来。** 跟它说"帮我连 QQ"，它会准备 NapCat；
> 二维码出来还是要你手机扫。

**这一步风险最高，想清楚再点。**

面板上点 QQ 那张的「**连接 QQ**」。

你需要：

- **两个 QQ 号**：你自己的，和一个**给她专用的**
- 手机上装 QQ（用来扫码）

流程：

1. 填两个不同的 QQ 号
2. 勾选两个确认（版本/哈希 + 执行）
3. 插件下载官方便携版 NapCat（约 118 MB）
4. 屏幕上出现二维码，**用手机 QQ 扫码登录那个小号**
5. 登录成功后，用你的主号私聊那个小号，她就会回你

**先看面板上那段风险提示**：小号容易触发风控，可能隔一阵要重新扫码，**不推荐用主号**，风险自负。

---

## 第 8 步（可选）：让她刷 B站

> **可以交给 DSH 做，但扫码必须你自己来。**

面板上点 B站 那张的「**扫码连接 B站**」。

用 **B站 App** 扫屏幕上的二维码，在手机上确认。

确认后登录态存本地，之后她可以看视频内容、评论、动态等。

同样注意风险提示：自动化操作可能违反 B站协议，账号可能被限制。

---

## 第 9 步（可选）：让她自己写日记

面板往下滚，有「**陪伴日常**」三个开关，**默认全关**：

- 会自己接着做
- 会主动找你
- 会写自己的日记

要用的话：

1. 先另装 `dsh-proactive@0.3.1`（**不随本插件安装**）
2. 回来打开开关
3. 保存

**没装那个插件的话，开关会显示"不可用"**——这是诚实，不是坏了。

---

## 用完想删

1. 面板里先把 Minecraft 世界**显式关闭**（别直接删文件）
2. 命令提示符执行：

```
dsh plugin --profile desktop remove dsh-companion
```

3. 重启 DSH

**注意**：卸载**不会删你的日记和数据**。数据在你自己用户目录下的 `.dsh\companion` 文件夹。想彻底删，手动删那个文件夹。

---

## 卡住了怎么办

| 现象 | 先看这里 |
|---|---|
| 装完设置里没有「鲸屋」 | 是不是装到了别的 profile？是不是没重启 DSH？ |
| 面板能打开，聊天没反应 | 「宿主模型」那行写的什么？先让 DSH 自己能聊 |
| 人设保存不了 | 是不是超过 4000 字？右下角有计数 |
| 开世界卡住/失败 | 看 `runtime/world.log`；端口可能被占 |
| 世界开了但她不在 | 看 `runtime/mc/bot.log`；版本对不对 |
| QQ 一直离线 | NapCat 登录态、token、账号是不是同一个 |
| 面板上开关都是灰的 | 大概率是没装 `dsh-proactive` |

**提问题时带上**：插件版本、DSH 版本、哪个通道、报什么错。**别贴 Cookie 或整个凭据文件**。
