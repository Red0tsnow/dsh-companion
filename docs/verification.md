## 今日事故与行为回归

进程事实回归覆盖多个 Java/不同 jar、无关端口、陈旧时间、外部启动、进程消失、PID 复用、并发互斥和端口尚未监听时保留已核实进程。真实世界测试覆盖重复启动不增加 PID、旧失败记录后重启、坏 jar 及时失败及正常保存关闭。无法核实归属时不接管、不强停。

来源回归覆盖 QQ 回复回原目标、世界事件不冒充主人、游戏与 QQ 不串通道、重连及重复消息去重。迁移覆盖预览无写入、重复不覆盖、原件保留、链接越界拒绝、路径重写和迁入闹钟默认停用。

## 重现

```powershell
npm run build
npm test
npm run check
npm pack --dry-run --json
node tests/browser-panel.mjs
node tests/browser-onboarding.mjs
```

`scripts/verify-host.mjs`、`tests/browser-host.mjs` 和 `scripts/verify-lifecycle.mjs` 需要已准备的工作区隔离 DSH、fixture provider 及独立安装目录；不会自动使用或修改现有部署。Minecraft 的手动命令见其专属记录。运行证据保留在本地 `artifacts`，不进入插件包。

`node scripts/verify-onboarding.mjs --download` 明确允许下载官方组件到独立 `.dev` 目录，验证新世界与身体，最后正常关闭测试世界；不会启动 QQ 安装助手或登录平台账号。
